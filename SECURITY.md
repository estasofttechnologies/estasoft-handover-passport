# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"), or write to the maintainers through [estasoft.com](https://estasoft.com).

Include the plugin version, the WordPress and PHP versions, and steps to reproduce. You will get an acknowledgement, and a fix is announced in the changelog when it ships.

## Supported versions

Only the latest release receives security fixes.
