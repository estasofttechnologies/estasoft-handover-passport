# PDF library

This folder is generated by `bin/build-pdf-lib.php`. Do not edit it by hand.

It holds mPDF and the packages it needs, with every namespace prefixed by `Estasoft\HandoverPassport\Vendor` so it cannot clash with another plugin that ships the same library. Licences are in `licenses/`. The fonts are DejaVu Sans, regular and bold.
